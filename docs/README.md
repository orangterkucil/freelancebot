# Screenshots & demo assets

This folder holds visual assets referenced by the main README:

- `landing.png` — landing page hero (https://freelancebot-alpha.vercel.app)
- `order-detail.png` — order detail with agent chat + actions panel
- `demo.gif` — animated full-flow demo (client create → fund → freelancer submit → verify → release)

## How to capture

### Screenshots (Mac)

1. Open the live demo at https://freelancebot-alpha.vercel.app
2. Cmd+Shift+4 → drag a selection around the area you want
3. Save the resulting `.png` from Desktop into this folder
4. Recommended sizes: ~1600px wide for landing, ~1400px wide for order detail

### Screenshots (Windows)

Win+Shift+S → drag selection → paste into any image editor → save as PNG.

### GIF demo

Easiest tools (Mac):
- [Kap](https://getkap.co) — free, native, exports straight to GIF
- [LICEcap](https://www.cockos.com/licecap/) — older but still works

Suggested recording:
- ~60–90 seconds
- Resolution: 1280×720 max (keeps file size small)
- 12–15 fps
- Sequence: landing → click "I'm a client" → create order → fund (simulated) → switch to freelancer tab → submit deliverable → see verdict → switch back to client → approve and release → final Released status

Save as `demo.gif` in this folder. Try to keep under 8 MB so it loads fast in the README.

## Why this matters

Judges scroll fast. A GIF in the first 30% of the README does more for credibility than five paragraphs of architecture explanation.
